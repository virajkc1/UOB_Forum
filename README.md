# Student Q&A Forum

A MERN stack application built with TypeScript where students can ask and answer questions.

## Project Structure

```
Forum Site/
├── client/          # React frontend with TypeScript
├── server/          # Node.js/Express backend with TypeScript
└── README.md        # Project documentation
```

## Features (Planned)

- ✅ Student authentication (login/register)
- ✅ Post questions on forum
- ✅ Answer other students' questions
- ✅ View all questions and answers

## Tech Stack

- **Frontend:** React + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **Database:** MongoDB
- **Authentication:** JWT tokens
